1. AKAR MASALAH TEKNIS SEBENARNYA (ROOT CAUSE ANALYSIS):
--------------------------------------------------------------------------------
Gejala yang sempat terjadi:
1. Error: "Could not remove the current plugin"
2. Dashboard WordPress memunculkan 2 baris plugin "WP Speed Core" kembar
3. Error: "Plugin file does not exist" saat tombol aktivasi ditekan

PENYEBAB UTAMA:
- Paket arsip zip awal dibuat di sistem operasi Windows menggunakan PowerShell 
  bawaan (Compress-Archive) yang menyimpan direktori dengan separator backslash (\).
  Contoh entri arsip cacat:
  * `wp-speed-core\wp-speed-core.php`
  * `wp-speed-core\assets\css\pagespeed-gauge.css`
  * `wp-speed-core\includes\class-bootstrap.php`

- Server web hajidantravelumroh.com menggunakan sistem operasi Linux. Di Linux, 
  karakter backslash (\) BUKANLAH pemisah folder, melainkan dibaca sebagai 
  karakter teks biasa dalam nama file.
- Dampaknya:
  * Linux mengekstrak file dengan nama harfiah datar (flat file), bukan subfolder.
  * WordPress Uninstaller gagal menghapus file berkarakter (\) sehingga memunculkan 
    pesan "Could not remove the current plugin".
  * WordPress otomatis membuat folder alternatif bernomor (`wp-speed-core-1` dan 
    `wp-speed-core-2`), yang menyebabkan plugin tampil ganda di wp-admin/plugins.php.
  * Saat aktivasi dicoba, WordPress mencari `wp-speed-core.php` standar dan gagal 
    karena nama file fisik di server adalah `wp-speed-core\wp-speed-core.php`, 
    sehingga memunculkan pesan "Plugin file does not exist".

* PERINGATAN KRITIS: 
  Mengunduh ulang dari aset rilis GitHub lama yang belum dinormalisasi akan 
  mengulangi siklus error yang sama. Gunakan berkas zip steril yang telah 
  dinormalisasi dengan forward slash standar Linux (/).
