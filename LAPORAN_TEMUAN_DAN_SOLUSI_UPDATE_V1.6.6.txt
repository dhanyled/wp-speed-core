2. AKAR MASALAH TEKNIS (ROOT CAUSE ANALYSIS)
================================================================================

A. Inkompatibilitas Separator Path Windows vs Linux pada Pembuatan Arsip ZIP
---------------------------------------------------------------------------
- Paket rilis `wp-speed-core.zip` sebelumnya dibuat menggunakan perintah 
  PowerShell Windows `Compress-Archive`.
- Pada sistem operasi Windows, pemisah folder menggunakan karakter backslash (\).
  Arsip zip yang dihasilkan mencatat nama-nama entri file dengan backslash:
  Contoh entri arsip:
  - `wp-speed-core\wp-speed-core.php`
  - `wp-speed-core\assets\css\pagespeed-gauge.css`
  - `wp-speed-core\includes\class-bootstrap.php`

- Menurut spesifikasi resmi PKWARE ZIP (APPNOTE.TXT Bab 4.4.17.1), seluruh pemisah 
  direktori dalam berkas ZIP WAJIB menggunakan forward slash (/).

B. Reaksi Web Server Hosting Berbasis Linux
-------------------------------------------
- Server hosting hajidantravelumroh.com berjalan di atas sistem operasi Linux.
- Di Linux, karakter backslash (\) BUKANLAH pemisah direktori, melainkan dianggap 
  sebagai karakter teks biasa dalam penamaan berkas.
- Akibatnya, saat WordPress mengekstrak berkas zip tersebut:
  1. Linux TIDAK MEMBUAT subfolder `assets/` atau `includes/`.
  2. Linux malah membuat berkas-berkas datar (flat files) dengan nama harfiah 
     `wp-speed-core\assets\css\pagespeed-gauge.css` dan 
     `wp-speed-core\wp-speed-core.php`.

C. Dampak Berantai yang Terjadi
--------------------------------
1. Mengapa Error "Could not remove the current plugin"?
   Karena struktur direktori yang rusak dan nama file mengandung karakter (\), 
   fungsi uninstaller bawaan WordPress (WP_Filesystem) gagal menghapus berkas 
   tersebut secara otomatis karena tidak menemukan hierarki folder standar.

2. Mengapa Muncul 2 Plugin di Dashboard?
   Karena proses replace gagal menghapus folder lama, WordPress membuat folder 
   tambahan dengan penomoran otomatis (`wp-speed-core-1` dan `wp-speed-core-2`). 
   WordPress kemudian membaca deklarasi header plugin dari kedua folder tersebut 
   sehingga menampilkan 2 baris di tabel Plugins.

3. Mengapa Error "Plugin file does not exist"?
   Di dalam folder ekstraksi, file utama bernama `wp-speed-core\wp-speed-core.php` 
   (termasuk karakter backslash dalam namanya). Ketika WordPress mencari file 
   standar `wp-speed-core.php`, sistem melaporkan file tidak ditemukan 
   (file does not exist).

  Plugins > Add New Plugin > Upload Plugin (Tambah Baru > Unggah Plugin).

  C:\Users\User\Downloads\wp-speed-core.zip
- Klik tombol "Install Now" (Pasang Sekarang).

LANGKAH 3: Aktifkan Plugin
--------------------------
- Klik tombol biru "Activate Plugin" (Aktifkan Plugin).
- Selesai! Plugin WP Speed Core v1.6.6 kini akan aktif secara normal, 
  hanya tampil 1 baris di tabel plugins, dan seluruh konfigurasi optimasi 
  lama Anda langsung berjalan otomatis.
